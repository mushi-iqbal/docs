## Overview

SaleTides allows you to create multiple user accounts within your dashboard, each with their own login credentials. This is useful for giving team members, analysts, or agencies access to your store analytics without sharing your main account credentials.

Navigate to **Settings → Users** to manage users.

## Adding a user

Click **Create User** and fill in:

- **Name** — the user's display name
- **Email** — their login email address
- **Password** — initial password (they can change it after logging in)
- **Permissions** — what areas of the dashboard they can access

Click **Save** to create the user. They can now log in at your SaleTides subdomain (`yourstore.saletides.com`) using the credentials you provided.

## User permissions

When creating or editing a user, you can configure which sections they can access:

| Permission | What it grants |
|---|---|
| **Dashboard** | View the main dashboard |
| **Orders** | View order data and reports |
| **Customers** | View customer data |
| **Products** | View product analytics |
| **Revenue** | View revenue reports |
| **Refunds** | View refund data |
| **Coupons** | View coupon analytics |
| **Subscriptions** | View subscription data |
| **Cohorts** | View cohort analysis |
| **Segments** | Create and manage segments |
| **Settings** | Access settings (typically admin only) |

## Activating and deactivating users

Users can be temporarily deactivated without being deleted. A deactivated user cannot log in until reactivated. This is useful for offboarding team members while preserving audit history.

To deactivate a user: click their name in the user list and toggle **Active** to off.

## Changing a user's password

Click a user's name → **Edit** → enter a new password and save. You can also send the user a password reset link from the edit page.

## Deleting a user

Click a user's name → **Delete**. Deleted users cannot be recovered. Their historical activity and any segments or settings they created remain in place.

<Warning>
You cannot delete your own account from the user management page. To delete your entire SaleTides account, use the **Delete Account** option in [Data Management](/settings/data-management).
</Warning>

## Your own profile

To update your own name, avatar, or password, click your avatar in the top right → **Profile**. Your email address cannot be changed from the dashboard — contact support if you need to update it.
