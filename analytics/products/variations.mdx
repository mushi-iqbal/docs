## What variation analytics covers

For WooCommerce variable products, SaleTides tracks the performance of each individual variation — not just the parent product. This lets you see exactly which sizes, colors, or attribute combinations are selling.

Navigate to **Products → Variations** to access variation data.

## Variations list

| Column | Description |
|---|---|
| Product | Parent product name |
| Variation | Attribute combination (e.g., "Red / Large") |
| SKU | Variation SKU |
| Orders | Number of orders containing this variation |
| Units Sold | Total quantity sold |
| Revenue | Gross revenue |
| Avg Price | Average selling price |

## Filtering variations

- **Search** by product name, variation name, or SKU
- **Filter by attribute** — e.g., show all "Large" variations, or all "Blue" variations
- **Filter by product** — narrow to a specific parent product's variations
- **Custom segment** — apply a saved variation segment

## Grouping by attribute

Use the **Group by attribute** control to aggregate variation data by a single attribute value. For example:

- Group by **Color**: see total revenue for all "Red" variations across all products
- Group by **Size**: compare "Small" vs. "Medium" vs. "Large" performance store-wide

This is useful for understanding which attribute values drive the most revenue regardless of which specific products they belong to.

## Variation reports

The **Variation Reports** page shows:
- Revenue per variation
- Orders per variation
- Units per variation
- Comparison charts for top-performing variations

## Segment reports for variations

Create a [variation segment](/advanced/segments/overview) to filter variation data by custom criteria. For example:
- All variations with price > $50
- All "Out of stock" variations
- All variations in a specific category

Then run a report on that segment to see aggregated metrics.

## Exporting variation data

Click **Export** to download variation data as CSV or Excel. Includes product name, variation, SKU, orders, units sold, revenue, and average price.
