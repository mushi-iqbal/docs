## What the Orders section shows

The **Orders** section gives you a complete view of every order your store has received. It breaks down into two main views:

- **Orders list** — a searchable, filterable table of all orders
- **Order reports** — aggregated analytics and charts

## Orders list

The orders table displays all orders with the following columns:

| Column | Description |
|---|---|
| Order # | WooCommerce order ID |
| Date | Order placement date/time |
| Customer | Customer name and email |
| Status | Current order status |
| Payment Method | How the order was paid |
| Items | Number of line items |
| Total | Order gross total |

### Searching and filtering

Use the search bar to find orders by order number, customer name, or email. Use the filter panel to narrow by:

- **Date range**
- **Order status** (completed, processing, on-hold, cancelled, refunded, etc.)
- **Payment method**
- **Country**
- **Product** — orders containing a specific product
- **Custom segment** — apply a saved segment filter

### Order details

Click any order to view its full detail page:

- Line items with product names, quantities, and prices
- Customer billing and shipping addresses
- Payment method and transaction details
- Order notes (from WooCommerce)
- Order metadata
- Linked refunds (if any)

## Order metrics

At the top of the Orders page, four key metrics are always visible:

| Metric | What it measures |
|---|---|
| **Total Orders** | Number of orders in the selected date range |
| **Total Revenue** | Gross revenue (before refunds) |
| **Average Order Value** | Revenue ÷ order count |
| **Repeat Rate** | % of orders from customers who ordered before |

## Order charts

The **Orders charts** page provides deeper visual breakdowns:

- **Orders over time** — daily/weekly/monthly bar or line chart
- **Revenue over time** — gross revenue trend
- **Orders by status** — stacked chart showing status distribution
- **Orders by country** — geographic map and table
- **New vs. returning customers** — split of first-time vs. repeat buyers
- **Orders by day of week** — which days perform best
- **Orders by hour** — which hours see the most activity
- **Order value distribution** — histogram of order sizes
- **Item count distribution** — histogram of items per order
