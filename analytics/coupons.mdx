## Coupons overview

The **Coupons** section shows you how every coupon code has been used, how much revenue it drove, and how much discount was issued. Navigate to **Coupons** in the sidebar.

## Coupons list

| Column | Description |
|---|---|
| Coupon Code | The coupon code |
| Type | Discount type (%, fixed cart, fixed product) |
| Amount | Discount value |
| Uses | Number of times the coupon was used |
| Orders | Number of orders using this coupon |
| Revenue | Total revenue from orders using this coupon |
| Discount Given | Total discount amount issued |
| Customers | Unique customers who used this coupon |

## Coupon detail page

Click any coupon to view:
- Usage trend over time
- All orders that used this coupon
- Revenue and discount breakdown
- Customer list for this coupon

## Coupon segments

Create custom [coupon segments](/advanced/segments/overview) to filter coupon data by criteria — for example:
- Coupons with more than 50 uses
- Coupons used in a specific date range
- Coupons with a discount amount above 20%

## Coupon segment reports

Run a **Segment Report** on a coupon segment to see aggregated metrics for the orders that used coupons in your segment. Useful for analyzing the revenue impact of a category of promotions.

## Use cases

### Promotion ROI

Compare revenue generated vs. discount given for each coupon to understand whether a promotion was profitable.

### Coupon abuse detection

Identify coupons being used far more than intended, or by customers who should not have access to them.

### Influencer / affiliate tracking

If you give unique coupon codes to influencers or affiliates, SaleTides shows you exactly how much revenue each code drives.

### Repeat purchase incentives

Track whether coupons given to new customers drive meaningful repeat purchases.

## Exporting coupon data

Click **Export** to download the coupon list as CSV or Excel. Export a segment report by applying a coupon segment and clicking **Export Segment Report**.
