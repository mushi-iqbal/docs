## What they are

A webhook is a message WooCommerce sends when something changes, like a new order. SaleTides adds webhooks for orders, customers, products, coupons and subscriptions (created, updated and deleted) when you connect your store. Each message is signed with a secret, so SaleTides only accepts genuine messages from your store.

## Checking them

In WordPress, go to **WooCommerce → Settings → Advanced → Webhooks**. You'll see webhooks named for SaleTides with status **Active**, delivering to `saletides.com`.

## If a webhook is disabled

WooCommerce disables a webhook after several failed deliveries in a row, for example while your server was overloaded. You don't need to do anything: SaleTides checks its webhooks every hour and turns them back on, and its 15-minute check catches the orders in between.

If they keep being disabled:

- A security plugin or firewall may block outgoing requests to `saletides.com`. Allow them.
- Your hosting may limit outgoing requests or background tasks (WP-Cron). Ask your host.

## If webhooks are missing

SaleTides' hourly check recreates any that were deleted. If you delete them, changes still arrive through the 15-minute check in the meantime.

## Security

SaleTides' API access is read and write so it can manage its own webhooks. It doesn't change your orders, products, customers or settings.
