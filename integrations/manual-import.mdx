---
title: "Manual import"
description: "Re-import orders, customers, subscriptions, products, coupons or refunds from your store."
---

You rarely need this: webhooks and the 15-minute check keep everything current. Re-import when:

- Data looks incomplete after a long outage or after restoring your store from a backup.
- You changed many orders in bulk with a tool that doesn't fire webhooks.
- Support asks you to.

## How

Open **Settings → Tools**. Each data type has **Reimport**:

| Data | Options |
|---|---|
| Orders | All statuses, or only the statuses you choose |
| Customers | All customers |
| Subscriptions | All, or chosen statuses (Active, Pending, On Hold, Cancelled, Expired) |
| Products | All products, variations and categories |
| Coupons | All coupons |
| Refunds | All refunds |

## While it runs

Re-importing updates existing records and adds missing ones; it never creates duplicates and never deletes anything. Your reports keep working meanwhile and fill in as the import progresses. Only one import of each type runs at a time.

## If it stops

A stopped import shows why. SaleTides retries automatically every few minutes when it's safe; otherwise fix the cause (see [Troubleshooting imports](/integrations/troubleshooting-imports)) and click **Retry**: only the missing pages are fetched again. **Report** sends the details to us.
