## How to create a segment

Navigate to **Segments** in the sidebar and click **Create Segment**, or click **Save as Segment** from any filter panel on a report page.

## Step 1 — Choose the segment type

Select what type of records this segment will filter:

- **Orders** — filter WooCommerce orders
- **Customers** — filter customer records
- **Products** — filter products and variations
- **Subscriptions** — filter subscription records

## Step 2 — Add conditions

Add one or more conditions. Each condition has three parts:

```
[Attribute]   [Operator]   [Value]
Country       is           United States
Total spent   greater than $500
Order count   between      3 and 10
```

### Available attributes by segment type

**Order segment attributes:**

| Attribute | Example |
|---|---|
| Order status | is Completed |
| Payment method | is Stripe |
| Billing country | is United States |
| Billing state | is California |
| Order total | is greater than $100 |
| Order date | is in the last 30 days |
| Coupon used | is (any coupon) |
| Contains product | is [Product Name] |

**Customer segment attributes:**

| Attribute | Example |
|---|---|
| Billing country | is United Kingdom |
| Billing state | is Texas |
| Billing city | is London |
| First order date | is before January 2024 |
| Last order date | is in the last 90 days |
| Total order count | is greater than 5 |
| Lifetime value | is greater than $500 |
| WooCommerce role | is Wholesale Customer |

**Product segment attributes:**

| Attribute | Example |
|---|---|
| Product name | contains "Bundle" |
| SKU | starts with "BLK-" |
| Category | is Apparel |
| Price | is greater than $50 |

**Subscription segment attributes:**

| Attribute | Example |
|---|---|
| Status | is Active |
| Subscription product | is [Plan Name] |
| Start date | is before January 2024 |
| Recurring amount | is greater than $50 |
| Billing period | is Monthly |

## Step 3 — Combine conditions

Multiple conditions use **AND logic** by default — a record must match all conditions to be included.

For example:
- Country = United States **AND**
- Total spent > $500 **AND**
- Order count > 3

This gives you "high-value US repeat customers."

## Step 4 — Name and save

Give your segment a descriptive name — for example, "High-Value UK Repeat Customers" or "Completed Orders with Stripe - Last 90 Days." Click **Save Segment**.

Your segment is now available across all analytics pages.

## Example segments to get started

**High-value repeat customers**
- Customer: Total order count > 3
- Customer: Lifetime value > $300

**New customers this quarter**
- Customer: First order date is in the last 90 days
- Customer: Total order count = 1

**Large orders via PayPal**
- Order: Payment method = PayPal
- Order: Total > $200

**Active subscribers on monthly plan**
- Subscription: Status = Active
- Subscription: Billing period = Monthly

**Products in the Apparel category priced over $50**
- Product: Category = Apparel
- Product: Price > 50
